# V4.3 航天影像与全中文展陈优化

## 本轮目标

校正航天图片与历史事件的对应关系，补强东方红一号与神舟五号的任务叙事，清除技术图中的外文标注，并为每项展陈图片明确中文身份。

## 修改前存在的问题

- 东方红一号与神舟五号的主视觉分别为馆藏实物、陈列模型，容易被误解为任务现场。
- 嫦娥一号、天问一号技术图存在法文标注。
- 图片卡片主要显示内部展示角色，未完整呈现面向参观者的类别、说明与来源。

## 本轮具体修改

- 新增东方红一号发射成功的 1970 年报纸历史档案，并改为东方红一号展厅主视觉；馆藏卫星实物保留为辅助展品。
- 新增杨利伟在神舟五号飞行期间的真实任务影像，并改为神舟五号展厅主视觉；陈列模型和复制品保留为馆藏展品。
- 以 SVG 重绘嫦娥一号构型、天问一号火星环绕和地火转移三张中文技术图。
- 为已展示的本地图片补充中文类别；图片卡片统一展示名称、类别、说明和来源。

## 新增或替换的图片

- 新增：东方红一号发射成功报道历史档案、神舟五号舱内任务影像。
- 替换：嫦娥一号 1 张、天问一号 2 张外文技术图替换为中文 SVG 重绘图。
- 停用：3 张原始外文技术图不再由页面引用，仍作为原始资料保留在本地目录。

## 图片来源

- 《人民日报》1970 年 4 月 26 日东方红一号报道：维基共享资源，公有领域。
- 杨利伟神舟五号舱内影像：中国新闻社供图，经维基共享资源发布，知识共享署名 4.0。
- 其余来源与中文重绘说明见 src/data/sources.json。

## 中文技术图处理方式

三张技术图均为基于已登记原始资料与公开任务流程制作的 SVG 中文重绘，非官方原图；未修改任何真实历史照片。
