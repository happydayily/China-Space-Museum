# Git 正式管理前的项目历史回顾

本文件整理 Git 正式接管项目以前已经完成的开发阶段。内容根据现有源码、数据、工具、截图和计划文档回顾而成，不代表这些阶段曾经存在对应的 Git 提交，也不应被解释为伪造的版本历史。

## V1：基础时间轴网页原型

完成中国航天发展历史时间轴的基础网页原型，建立项目最初的信息展示结构。

## V2：星空、航天视觉与初步交互

加入星空背景、航天主题视觉和初步交互，为后续三维数字博物馆方向奠定基础。

## V3.1：航天数据层

建立航天历史、任务、展厅和时间线等结构化数据层，使展示内容与页面组件逐步分离。

## V3.2：数字资产管理系统

建立图片、任务和展品等数字资产的登记和管理结构，为素材展示与质量维护提供基础。

## V3.3：图片自动采集和质量评分

补充图片自动采集、图片排序和质量评估工具，形成初步的素材处理流程。

## V3.4：重点航天素材

补充嫦娥、东方红、神舟、天宫、天问等重点航天主题素材。

## V4：数字博物馆五大主题展厅

建立数字博物馆整体框架和五大主题展厅，逐步加入展品、任务、时间线和三维视觉内容。

## V4.1：中文化、字体与图片角色调整

完成界面中文化，调整字体和页面文字表现，并修正图片在展厅中的角色和展示方式。

## V4.2：展陈布局、时间线与火箭谱系精修

完成展陈布局、历史时间线和长征系列火箭谱系的进一步精修，形成进入正式 Git 版本管理前的项目基线。

## 历史说明

以上阶段均发生在 Git 正式版本管理之前。当前首次 Git 提交只记录 V4.2 基线，不追溯创建不存在的历史提交。
