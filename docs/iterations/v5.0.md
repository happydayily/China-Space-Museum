# 中国航天数字博物馆 V5.0

## 1. 核心设计理念

将中国航天史呈现为一座可浏览的数字展馆：从建立体系、进入轨道，到载人航天、长期在轨、探月和行星际探测，强调能力如何逐步扩展。

## 2. 首页结构

首页由深色序厅 Hero、五大发展主线、入馆导言、关键时刻历史展墙和共同技术底座组成。五条主线用于导航，跨线关系说明运载、测控、导航等能力如何共同支撑不同任务。

## 3. 五大展厅结构

- 进入太空：以火箭高度、轨道运力和任务边界构成能力尺度比较。
- 天基中国：以“我在哪里、天气正在发生什么、从太空能看清什么”解释卫星到社会服务。
- 人在太空：沿无人验证、首次载人、出舱、交会对接、空间站和长期驻留推进。
- 奔向月球：用“绕 → 落 → 回”表达能力阶梯，并以月背采样支路收束。
- 走向行星：用距离、发射窗口、通信时延、自主运行和深空测控解释工程难度。

## 4. 主要内容变化

RC4 基础上完成正式版内容事实审计；删除无法由一手公开资料稳定确认的长征十号具体高度与运力数字。五厅继续维持差异化展陈，不恢复统一模板或大规模卡片阵列。

## 5. 数据与媒体来源原则

优先使用国家航天局、中国载人航天工程官网、北斗官网、中国气象局、中国科学院等主管机构资料。界面默认显示机构、年份和来源详情入口；作者、原始标题、URL、许可与授权说明放入展开区域。官方视频保持 link-only，不下载或嵌入未知播放器。

## 6. PC 支持范围

本版本只支持并验收 1600×900 PC 桌面端 fullPage 页面。移动端、平板端和响应式重构不属于 V5.0 范围。

Three.js 场景仍产生约 817 KB 的独立 chunk 警告；这是已拆分并延迟加载的视觉场景，未为消除警告进行大规模架构重构。未来规划类任务以公开状态展示，不代表已完成。
