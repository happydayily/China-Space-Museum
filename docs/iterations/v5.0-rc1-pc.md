# V5.0-RC1-PC 桌面数字博物馆终审迭代记录

## 一、迭代范围

本轮承接 V5.0-F，目标是完成 V5.0 正式候选版前的 PC 桌面终审。验收范围冻结为一个桌面视口：`1600×900`、浏览器缩放 100%、`fullPage: true`、PNG。首页和五座真实 GrandHall 展厅共生成六张图；本轮不生成手机端、平板端、`390×844`、`768px`、`1920×1080` 或其他视口截图，也不修改移动端和平板端响应式结构。

## 二、基线与实现

- 基线为 `main` 上的 V5.0-F 最终提交 `b7d11298eb92b2231dea985ee9f1705476fa9afe`，`main` 与 `origin/main` 一致，`v5.0-f` 已存在。
- 复用既有 Playwright 与本机 Edge/Chromium 能力，不重复安装工具；脚本从 `src/data/grandHalls.json` 读取五个真实展厅 ID，按真实 `#/grand-hall/:grandHallId` 路由截图。
- `scripts/capture-review-pages.mjs` 只保留一个 `1600×900` PC 页面，直接覆盖 `docs/screenshots/review/latest/` 下的六个固定文件，并在结束时安全关闭浏览器与临时 Vite 服务。
- 截图等待 DOM、网络空闲、字体、图片和短暂动画稳定；截图模式只暂停动画，不改变正常网页体验。自动检查非空文件、错误页、Vite 错误覆盖层、同源 404、console/pageerror、broken image、图片 alt、链接命名和横向溢出。

## 三、PC 展陈收束

### 首页

- Hero 保留深色入口和标题主导，加入低对比度地球轨道线与环形视觉重心，缓解 Three.js 在自动化环境不可见时的空场感。
- 五条发展主线保留 SVG 网络和真实路由；主线组增加键盘焦点状态，空格键不再触发页面滚动，Enter/Space 均可进入展厅。
- “中国航天关键时刻”将 1970 东方红一号、2003 神舟五号、2021 天问一号作为主要节点，其余节点降为辅助信息，保持时间顺序不变。
- “共同技术底座”保留五大方向，但降低连续竖直卡片边界，以短标记和安静分隔线呈现支撑关系。

### 五座主题展厅

- 进入太空：火箭阶梯直接显示高度与近地轨道运力，仍保留“查看参数”折叠区和代表任务；没有改变六枚火箭的连续比较。
- 天基中国：三项应用明确回答“我在哪里？／天气正在发生什么？／从太空能看清什么？”，保持导航、气象、遥感的不同观看关系。
- 人在太空：无人验证段改为“先验证系统，再把人员安全交给完整系统”，有人进入太空段补足载人飞行闭环，空间站段补足长期运营语义。
- 奔向月球：主路线仍为绕—落—回，补充绕月捕获、动力下降与悬停避障、采样起飞和月轨交会等动作信息。
- 走向行星：在地火概念距离图下增加“为什么不是直线？”说明，解释发射窗口、转移轨道、行星运动、通信时延和自主判断。
- Deep Dive 继续保持五厅差异化布局，没有恢复为统一三列模板。

## 四、性能与媒体策略

- `SpaceScene`、`GrandHallPage` 和 `HallPage` 改为 React lazy import。基线入口 JS 约 `1,087.49 kB`，本轮初始入口 chunk 约 `218.13 kB`；SpaceScene 独立 chunk 约 `816.52 kB`，因此 Vite 仍报告大 chunk 警告，未扩大为架构级性能专项。
- 本轮没有新增无法确认授权的本地图片或视频。继续使用项目已有登记素材；官方资料和视频保持 link-only。官方资料核验入口包括国家航天局、中国载人航天工程和中国气象局页面，授权不清晰的内容不复制进仓库。
- `index.html` 增加内联 favicon，消除自动验收时浏览器对 `/favicon.ico` 的 404 请求。
