## RC4.2 最终修正

`OfficialMediaCard` 的来源登记把明确许可证与补充授权说明分开处理：`license` 只显示在“许可”字段，`licenseNote` 只显示在“授权说明”字段。这样官方 link-only 资料仍保留完整来源与授权信息，但不会在展开面板中重复显示同一段文字。

RC4.1 已完成的策展去模板化全部保留：五厅专属 Deep Dive 标题与叙事入口、首页历史展墙、卫星“问题—结果—证据”链、载人三章人物节点、月背“通信 → 软着陆 → 采样返回”支路，以及低噪声行星工程链。
