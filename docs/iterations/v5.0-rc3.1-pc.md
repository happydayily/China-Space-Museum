# V5.0-RC3.1-PC 策展与内容深化记录

## 本轮定位

本轮承接 `v5.0-rc2-pc`，继续只维护 `1600×900` PC 桌面端。移动端、平板端和响应式重构冻结；本轮不修改一键启动器，不新增未经授权的本地媒体，不创建正式 `v5.0` Tag。

目标是把 RC2 的页面结构再向“中国航天发展史数字博物馆”推进一层：首页承担序厅导言，五条主线和五个展厅承担不同的历史叙事，事实信息与展品关系优先于页面装饰。

## RC3 审计结论

- `main` 与 `origin/main` 在 `84566563a92855ca6e310157c5ac4e9d1dc43394` 一致，工作树干净。
- 现有五个 Grand Hall Story 已经是独立组件；进入太空、天基中国、人在太空、奔向月球、走向行星分别使用运力、应用、章节、路线和距离叙事。
- 旧版主线年份轴漏掉 1988、2013、2016、2021，导致部分节点不能落在正确年份位置；首页时间线的主次样式也与数据标记不一致。
- RC2 基线构建与浏览器基线没有发现 console error、同源 404、broken image 或横向溢出；六张 PC 截图继续作为人工验收依据。

## 本轮完成

### 首页与共同底座

- 增加“入馆导言”，用 1956、1970、2003、2024 四个尺度变化作为序厅阅读入口。
- 将主线年份轴补齐到实际关键节点，修复节点落在轴外的问题。
- 时间线主展项改由 `data-emphasis` 数据标记控制，弱化支撑节点，避免依赖卡片顺序。
- 技术底座从五项并列名片改为“能力 + 支撑关系”阅读，保留运载、测控、导航、材料与制造、空间科学五个方向。
- 去除普通阅读界面中的 `V5.0`、RC 等开发阶段痕迹，版本信息留在迭代文档和变更记录中。

### 五个主题展厅

- 进入太空：在火箭谱系后增加“高度—运力—轨道—任务”因果链，长征五号仍为大推力主展项，长征二号 F 保持载人高可靠配套位置。
- 天基中国：移除主叙事中的卫星网络仪表盘，改为“我在哪里？/ 天气正在发生什么？/ 从太空能看清什么？”三个生活问题，分别落到北斗、风云和高分；媒体仍按既有来源策略展示。
- 人在太空：在三章能力路线后增加三位与节点直接相关的航天员，以杨利伟、翟志刚和景海鹏作为历史语境中的少量人物，不展开人物百科。
- 奔向月球：保留“绕—落—回”主路线和月背支路，补充嫦娥六号于 2024 年从月球背面带回 1935.3 克样品的事实及中国国家航天局来源入口。
- 走向行星：在地球—转移轨道—火星—更远深空尺度图后补充“发射窗口—通信时延—自主运行”三项工程变化，不虚构具体时延数值。
