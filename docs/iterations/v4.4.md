# V4.4 重构任务过程与官方影像

## 本轮目标

删除五座展厅共用的模板化弧线轨迹，根据任务真实特征分别呈现历史流程、载人绕飞、探月任务、火星探测和空间站建造，并在每个任务过程后提供可靠的官方影像入口。

## 为什么删除原统一轨迹模板

原 `MissionTrajectory` 把所有任务压缩为相似的“地球—发射—轨道—返回”弧线。它无法解释东方红一号的历史传播意义、神舟五号14圈绕飞、嫦娥采样返回、天问一号绕落巡和空间站舱段转位，动画形式反而遮蔽了任务差异。

## 各任务展示方式

- 东方红一号：历史档案图片与四阶段时间线，不保留飞行小球。
- 神舟五号：近地绕飞动画、21小时23分与14圈统计、七阶段返回流程。
- 嫦娥系列：嫦娥一号/三号/五号/六号任务选择器、地球与月球双天体线路、逐阶段点亮；嫦娥六号完整呈现十一阶段。
- 天问一号：太阳—地球—火星关系图，以及“奔火、落火、巡火”三章十阶段。
- 中国空间站：天和、问天、梦天舱段转位组装动画和八阶段建造过程。

## 新增官方影像

新增9条链接，来源仅包括中国国家航天局、中国载人航天工程官网和新华网：东方红一号50周年回顾、神舟五号专题、嫦娥五号专题、嫦娥六号任务图集、天问一号落火与祝融号实拍、中国空间站问天转位、历次构型图和梦天转位回顾。

## 哪些任务仍保留动画

- 神舟五号保留近地轨道绕飞动画，并由真实阶段文字驱动。
- 嫦娥系列使用地月线路进度动画。
- 天问一号使用章节切换与着陆/巡视状态动画。
- 中国空间站使用舱段转位和组装动画。
- 东方红一号只使用阶段高亮，不保留轨迹动画。

## 技术实现

任务阶段集中保存在 `src/data/missionProcesses.json`；五种布局位于 `src/components/MissionProcess/`。官方影像保存于 `src/data/mediaLinks.json`，页面统一采用外链卡片，不下载大型视频文件，不做不稳定播放器嵌入。

## 人工验收结果

已通过本地浏览器 DOM 和截图验收：东方红一号不再出现轨迹画布；神舟五号显示14圈、21小时23分与七阶段；嫦娥六号显示十一阶段；天问一号分为奔火、落火、巡火；空间站显示八阶段舱段组装。五张截图已保存至 docs/screenshots/v4.4/。

## 构建结果

npm run build 通过，Vite 完成生产构建；仅保留既有的大包体积提示，无构建错误。

## 尚未解决的问题

部分国家航天局和中国载人航天多媒体页面不允许通用阅读器稳定抓取，因此本版本以官方外链打开，不内嵌视频。神舟五号官方专题和其余官方页面标题、来源域名已核对。
