# V5.0-E3 迭代记录：五大主线与数字博物馆展陈基线

迭代日期：2026-08-27
基线版本：V4.4.1（提交 `83c0eac7598a64928aaee1c761154807e4f33db8`）
当前检查点：V5.0-E3 归档

## 一、迭代目标

本轮在 V5.0-E2 的媒体融合基础上，完成 V5.0-E3 展陈视觉基线。目标是让项目从“结构完整的航天主题网页”进一步呈现为“具有数字博物馆层级的中国航天史展览”，同时保留 V4.4.1 的任务详情、Three.js 场景、图片体系、任务过程和官方媒体入口。

本轮不进入 V5.0-F，不进行大规模历史清理、性能拆分、Git 历史重写、批量下载未经核实的素材或新建大量页面。

## 二、从 V4.4.1 到 V5.0-E3 的主要变化

### 1. 五大发展主线

首页以五条主线组织中国航天发展史：进入太空、天基中国、人在太空、奔向月球、走向行星。主线数据集中在 `src/data/developmentLines.json`，用于总览、时间关系和展厅导航。

### 2. 五大主题展厅

五条主线分别对应五座 GrandHall：运载火箭与发射体系、卫星应用体系、载人航天与空间站、探月工程、行星际探测。展厅数据集中在 `src/data/grandHalls.json`，包含展厅问题、展厅级重要性说明、节点、关系和未来方向。

### 3. GrandHall 路由与三层结构

新增真实展厅路径：

```text
#/                         首页序厅
#/grand-hall/:grandHallId  五大主题展厅
#/hall/:missionId          既有任务/展项详情
```

旧任务详情仍可通过原路径访问，任务页通过所属展厅信息返回上一级。这样首页、主题展厅和具体任务详情形成三层结构，没有把旧任务页继续伪装成一级展厅。

### 4. 五个独立 Story

- 进入太空：运力阶梯、火箭高度和不同轨道任务。
- 天基中国：东方红一号、卫星应用网络、导航、气象和遥感。
- 人在太空：无人验证、载人飞行、交会对接和空间站长期运营。
- 奔向月球：绕、落、回、月背通信与采样返回。
- 走向行星：地月系统之外的距离、通信时延、环绕、着陆和巡视。

每个 Story 都是独立组件，不再使用一个通用任务轨迹模板替代五种不同的航天叙事。

### 5. 两级“为什么重要”

展厅使用 `hallWhyItMatters`，解释一整条发展路线为何重要；具体任务使用 `whyItMatters`，解释一个任务或展项在中国航天史上的位置。两者不混用。

### 6. 官方媒体与开放许可素材

官方媒体以来源链接为主，不嵌入不稳定的跨站播放器；开放许可素材记录标题、来源、作者、许可证和许可证链接，并在本地保存经过整理的 WebP。媒体在 Story 的相应叙事节点出现，而不是统一堆叠在页面底部。

普通页面默认显示中文标题、年份、来源机构和许可证简写；英文文件名、作者、完整署名、`sourceUrl` 和 `licenseUrl` 收进“来源详情”。

### 7. 深浅交替的博物馆视觉基底

首页保留首屏深色 Hero，主线地图、关键时刻使用浅色纸张背景，共同技术底座保留深色。五个展厅保留深色 Hero 和必要的火箭、轨迹、卫星系统、地月与行星际暗场；为什么重要、主体叙事、媒体和结尾回到轻量纸张或冷灰背景。五厅强调色采用低饱和铜橙、蓝青、灰绿、灰紫和沙红。

同时完成字体层级收束，减少发光、模糊、厚重阴影、大面积渐变和密集软件卡片感，保留细分隔线、留白和内容关系。

## 三、自动验收截图

新增 `scripts/capture-review-pages.mjs` 和 `npm run screenshots`。脚本会：

1. 读取 `grandHalls.json` 的真实展厅 ID；
2. 必要时启动本地 Vite 预览服务；
3. 使用本机 Edge/Chrome，以 1600×900 视口访问首页和五个展厅；
4. 等待 DOM、字体、图片和 React 内容稳定，并在截图模式暂停动画；
5. 检查图片失败、Vite 错误覆盖层、明显错误页、缺失文件和零字节文件；
6. 将六张 fullPage PNG 固定覆盖到 `docs/screenshots/review/latest/`。

V5.0-E3 验收图已复制到 `docs/screenshots/v5.0-e3/`，作为本轮视觉状态的正式归档。普通开发运行只覆盖 `latest`，不会生成时间戳截图或浏览器缓存。
