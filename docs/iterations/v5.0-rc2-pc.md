# V5.0-RC2-PC 产品化与桌面端终审迭代记录

## 一、范围

本轮承接 V5.0-RC1-PC 清理提交 `227004af3f3c453c99d0e3716f1c9efa45b67e8e`，只维护 `1600×900` Microsoft Edge PC 端。移动端、平板端、390px、768px 和响应式全面重构均冻结，不进入 RC3。

## 二、产品化实现

- 新增根目录 `中国航天博物馆启动器.cmd`，作为用户双击入口。
- 新增纯 CMD 根目录启动器，检查 `node_modules`、调用 `npm.cmd run dev`、等待本地服务并打开正确的 `/China-Space-Museum/` localhost URL；不使用 PowerShell，不联网下载。
- 首页顶栏增加低权重“在线展馆”入口，指向 GitHub Pages。在线版和本地版共用同一套页面内容。

## 三、PC 展陈终审

复核 RC1-PC 六张 PC 截图：首页 Hero、五条主线、关键时刻和共同技术底座；进入太空的火箭尺度与真实展品；天基中国的导航/气象/遥感关系；人在太空的无人验证—载人—空间站章节；奔向月球的绕—落—回路线；走向行星的距离、时间、通信与自主逻辑。没有发现需要推倒重做的 PC 结构问题，因此只加入产品化入口，不新增媒体。

## 四、验证要求

- `npm.cmd run build`：通过；保留既有 `SpaceScene` 大 chunk 警告。
- `npm.cmd run screenshots`：只生成 `docs/screenshots/review/latest/` 下六张 `1600×900` fullPage PNG。
- 真实浏览器检查首页、五厅、旧任务路由、图片、官方媒体链接、console、同源 404、broken image、横向溢出、SVG 主线点击和火箭参数展开。
- 启动器检查本地环境、端口处理、本地 URL 和 Edge 自动打开。

RC2-PC 完成产品化入口和 PC 桌面终审，不创建正式 `v5.0` Tag；完成验收后创建 `v5.0-rc2-pc` 检查点并等待后续指令。
