# V5.0 内容事实审计

审计范围：正式版页面实际显示的首页、五大发展主线、五个展厅及任务详情中的历史节点。核验重点是年份、任务状态和页面使用的具体数字；规划内容保持“规划中”状态。

## 核验结论

- 1956：中国航天事业起步，页面使用国防部第五研究院成立作为体系化起点。
- 1970：东方红一号发射成功，页面将其作为卫星时代与进入轨道的起点。
- 1992：921 工程正式立项，页面用于载人航天工程起点。
- 2003：神舟五号完成中国首次载人航天飞行。
- 2007：嫦娥一号进入绕月轨道，页面用于“绕”。
- 2020：北斗三号全球卫星导航系统正式开通；嫦娥五号完成月球采样返回。
- 2021：天问一号完成火星环绕、着陆与巡视任务闭环；祝融号在火星表面工作。
- 2022：中国空间站天和、问天、梦天三舱基本构型建成并转入应用发展阶段。
- 2024：嫦娥六号实现人类首次月球背面采样返回，官方公布样品总量为 1935.3 克。

## 火箭与状态

页面中的长征一号、长征二号 F、长征三号 B、长征五号和长征七号首飞年份、代表任务与已完成状态与现有官方/工程资料及项目来源登记一致。高度和运力属于型号参数，页面以“约”或轨道类型限定，未将不同构型或不同任务条件混为同一指标。

长征十号仍处于规划/研制阶段。由于本轮未找到足以稳定支撑页面具体高度和地月转移运力数字的一手公开页面，已删除原有“约 92 米”“约 27 吨”两项数字，改为“面向载人月球探测的地月转移能力（规划）”。页面没有把载人登月或后续行星探测规划写成已完成事实。

## 五厅专项核验

- 天基中国：东方红一号、返回式卫星、风云、高分与北斗分别被呈现为历史起点、回收/遥感、气象、对地观测和导航服务；页面表达的是“卫星 → 数据 → 服务”，未把型号目录当成主体。
- 人在太空：921 工程、神舟一号至四号无人验证、神舟五号首次载人、神舟七号出舱、天宫交会对接和空间站建造/运营顺序正确。
- 奔向月球：嫦娥一号/二号对应绕月，嫦娥三号/四号对应软着陆与巡视，嫦娥五号完成月面采样返回，嫦娥六号完成月背采样返回；中继通信、采样、上升与交会对接作为工程能力说明。
- 走向行星：天问一号 2020 年发射，2021 年完成火星捕获、着陆和祝融号巡视；发射窗口、转移轨道、通信时延、自主运行和深空测控作为难度解释；小行星、火星采样返回等只标为规划。
