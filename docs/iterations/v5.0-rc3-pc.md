# V5.0-RC3-PC 内容、策展与视觉终审记录

## 版本结论

RC3-PC 是基于 `v5.0-rc2-pc` 的桌面端候选终版，目标为“中国航天发展史数字博物馆”的内容、策展、视觉和 PC 体验终审。全程只维护 `1600×900` 桌面端；移动端、平板端和响应式重构冻结，不创建正式 `v5.0` Tag。

本轮分为三个独立提交：

- RC3.1：`V5.0-RC3.1-PC：策展与内容深化`
- RC3.2：`V5.0-RC3.2-PC：视觉与展陈终审`
- RC3.3：本记录、最终 QA 与版本候选收口

## 主要结果

### 序厅与共同结构

- 首页增加入馆导言，用 1956、1970、2003、2024 四个节点把 Hero、五条主线和后续展厅串成历史序言。
- 主线年份轴补齐 1988、2013、2016、2021 等已使用节点，所有展示节点落在实际年份位置。
- 关键时刻使用数据标记控制主次，技术底座强调“能力—支撑关系”，减少 Dashboard 式等权模块。
- 普通阅读界面去除 V5.0、RC 等开发阶段标识，版本信息保留在文档和更新日志。

### 五个不同展厅

- 进入太空：高度、运力、轨道、任务边界；长征五号是大推力主展项，长征二号 F 作为载人高可靠配套。
- 天基中国：从星座图转向“我在哪里？/ 天气正在发生什么？/ 从太空能看清什么？”三个日常问题，分别对应北斗、风云、高分。
- 人在太空：无人验证—首次载人—交会对接—空间站长期运营，人物只保留杨利伟、翟志刚、景海鹏三个能力节点语境。
- 奔向月球：绕—落—回主路线与月背支路，补充嫦娥六号 2024 年月背采样返回及 1935.3 克样品事实。
- 走向行星：地球—转移轨道—火星—更远深空，明确发射窗口、通信时延和自主运行带来的工程变化。

## 最终判断

**B：具备进入人工终审和正式版本决策的条件，但不自动创建正式 `v5.0`。**

RC3 已达到桌面端候选终版状态；剩余事项主要是用户对六张 PC 长截图的人工确认、历史素材授权持续维护和独立性能优化，不再属于本轮网页内容开发。
