# V5.0-RC3.2-PC 视觉与展陈终审记录

## 本轮定位

本轮承接本地 RC3.1 提交 `e65b5e0`，只维护 `1600×900` PC 桌面端。移动端、平板端和响应式重构冻结；本轮不修改启动器、不新增媒体、不创建正式 `v5.0` Tag。

## 完成本轮

- 复核首页入馆导言、时间线主次层级、技术底座关系和五厅新增信息块在长页面中的垂直节奏。
- 将来源行、来源详情、授权状态和外链动作保持在低视觉权重；来源详情继续默认折叠，媒体展品保持为主体。
- 修正新增卫星、运载、载人、探月、行星信息块在浅色正文中的文字对比度。
- 为新增信息块增加克制的 hover/focus 状态；保留既有火箭参数、StoryTour、主线 SVG 键盘入口和外链 `noreferrer`。
- 载人展厅导览从“三个人的阶段”修正为“三章路线”，让人物信息回到能力叙事的上下文中。

## 验收

- `npm.cmd run build`：通过；仅保留既有 SpaceScene 大 chunk 警告。
- `npm.cmd run screenshots`：通过；只生成六张 `1600×900` PC fullPage PNG：`01-home.png` 至 `06-planetary.png`。
- 六张截图已人工读取：没有发现新增遮挡、文字被浅底吞没、横向溢出、媒体比例异常或来源层级抢主体问题。
- 使用本机 Microsoft Edge 复核首页、五个主题展厅和旧任务页；生产截图脚本同时检查图片、同源 404、运行时错误、console error、链接命名和桌面横向溢出。
