# V5.0-E4 展陈深化与视觉终审迭代记录

## 迭代范围

本轮承接 V5.0-E3，继续维护进入太空、天基中国、人在太空、奔向月球、走向行星五条发展主线和五座主题展厅。E4 只做展陈深化、重点展项和视觉缺陷修复；完成两轮后停止，不进入 V5.0-F。

E3 已在 `7aca552` 建立 GitHub 检查点，E4.1 和 E4.2 分别形成以下独立提交：

- `8df0035`：`V5.0-E4.1：修复展厅视觉缺陷与媒体布局`
- `084f6e8`：`V5.0-E4.2：深化五厅展陈与重点展项`

## E4.1：修复视觉缺陷与媒体布局

- 新增五厅共用的轻量本厅导览，提供概览、核心叙事、重点展项和下一步入口。
- 为展厅 Hero 文本增加标题安全区，限制视觉容器溢出，避免标题被右侧场景或媒体遮挡。
- 进入太空恢复六枚火箭的连续运力阶梯；长征五号转运图和长征二号 F 影像改放到阶梯后的媒体展陈区。
- 将新增开放许可素材的可见标题调整为中文，来源详情仍可折叠查看。

## E4.2：深化五厅重点展项

新增“数字博物馆第二层”组件。每座展厅最多展示三个重点展项，并根据展厅主题混用真实图片、历史档案、CSS 信息图和任务入口：

- 进入太空：东方红一号与长征一号、长征二号 F 与载人运输体系、长征五号与大推力时代。
- 天基中国：北斗三号、风云、高分。
- 人在太空：神舟五号、交会对接、中国空间站。
- 奔向月球：嫦娥一号绕月、嫦娥三号/四号落月与月背、嫦娥五号/六号采样返回。
- 走向行星：天问一号绕落巡、祝融号、下一阶段行星际探索。

本轮没有新增无法确认来源的媒体；继续使用官方媒体入口、开放许可本地素材和已有来源登记。任务级 `whyItMatters`、展厅级 `hallWhyItMatters`、真实 `#/grand-hall/:grandHallId` 路由和五个独立 Story 均保持有效。

## 自动验收

E4.1、E4.2 均执行构建和自动截图。最终执行结果：

- `npm.cmd run build` 通过；仅保留生产 JavaScript chunk 较大的既有警告。
- `npm.cmd run screenshots` 通过，自动读取 `grandHalls.json` 的真实展厅 ID。
- 统一视口为 1600×900，六张图片均使用 `fullPage: true` 和 PNG 格式。
- 脚本检查六个文件存在且非空，并检查图片加载失败、错误覆盖层和明显错误页。

## 当前遗留问题

- 生产构建仍有较大的 JavaScript chunk 警告，性能拆分不属于本轮范围。
- 部分 V4 旧任务影像仍需继续补强授权和来源核验。
- 移动端导览采用横向滚动，后续如继续迭代可单独做响应式细化。
