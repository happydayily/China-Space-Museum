# V5.0-RC1-PC 桌面终审计划

## 目标

只针对桌面 PC 端完成正式 V5.0 发布前的深度终审，固定验收 `1600×900` 一个视口。保留首页、五条发展主线、五座主题展厅、真实 GrandHall 路由、五个独立 Story、Deep Dive 第二层、官方媒体与开放许可素材体系，以及深色 Hero 加浅色正文的总体方向。本轮不生成或调整手机、平板截图和响应式结构。

## 执行步骤

1. 基线：执行 `git status`、`git branch`、`git tag`、`git log -5 --oneline`、`git fetch origin`，确认 `main` 与 `origin/main` 一致、`v5.0-f` 存在且工作区干净；执行既有构建和截图流程，读取 E4/F 的桌面基线。
2. 检查：检查首页 Hero、五条主线、关键时刻、共同技术底座，以及五厅的 Hero、展品层、Deep Dive、导览、来源和交互；重点寻找遮挡、碰撞、留白、重复素材、来源抢视觉、字号失衡、五厅趋同和 PC 横向溢出。
3. 取证：使用 agent-reach 访问可靠官方或开放许可来源，优先核验中国国家航天局、中国载人航天工程、中国航天科技集团、新华社、中国气象局、北斗官网、中国科学院和 Wikimedia Commons。授权不清晰的素材只保留外链，不写入仓库。
4. 实施：只修改能直接改善 PC 展陈质量的源码、数据或来源记录；不做架构级重写，不增加正式 V5.0 标签，不将五厅重新模板化。每个修改批次执行 `npm.cmd run build` 和桌面截图。
5. 验收：只生成 `1600×900` 的首页和五厅六张 fullPage PNG；实际读取全部图片并检查标题遮挡、异常留白、图片比例、正文密度、来源层级、对齐和视觉重心。若有明显问题，只允许再修复一轮并重新截图。
6. 归档：最终截图直接保存到 `docs/screenshots/v5.0-rc1-pc/`，固定命名 `01-home.png` 至 `06-planetary.png`；不建立 `mobile/`、`tablet/`、`1600/` 或 `1920/` 子目录；更新 README、CHANGELOG、AI_DEVELOPMENT_LOG、迭代记录和中文提示词档案。
7. 发布检查点：创建最终提交 `V5.0-RC1-PC：完成桌面数字博物馆终审`，创建 annotated tag `v5.0-rc1-pc`，标签说明为 `V5.0-RC1-PC：中国航天数字博物馆桌面正式候选版`，按顺序推送 `main` 和该标签，核验 Pages workflow。

## 风险与回滚

- 不删除已有素材、标签或历史；不使用强制推送、镜像推送、`--tags` 或历史重写。
- 如果 PC 性能拆分需要架构级调整，则只记录现状和后续建议，不在本轮扩大范围。
- 如果来源许可不能明确确认，不下载、不转换、不新增本地媒体。
- 如果视觉检查没有发现必须修复的问题，保留现状，仅完成 PC 单一视口的正式验收和归档。
