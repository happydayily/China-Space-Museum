# V5.0-F 数字博物馆展览化执行计划

## 目标

以 V5.0-E4 为基线，不扩大页面数量，不推翻五条主线、五座展厅、GrandHall 路由、五个独立 Story、Deep Dive 第二层和既有媒体来源体系，将五厅重点展项从统一网页卡片推进为有主次、节奏和空间关系的数字博物馆展陈。

## 分轮任务

### F1：五厅展品化与视觉层级重构

- 为五厅 Deep Dive 建立不同的展陈布局：进入太空强调小、中、大尺度；天基中国强调观测图像与网络关系；人在太空改为纵向三幕；奔向月球改为连续路线与月面主视觉；走向行星强调旅程、表面和未来的距离节奏。
- 调整真实图片、说明文字和来源入口的层级，减少图片上的长文字和等权卡片。
- 增加可复用的展品编号、展品类型和简短图注语义，保留任务详情入口。
- 扩展自动截图脚本，保留六张 1600×900 desktop，并增加 390×844 mobile 六张到 `latest/mobile/`。
- 每项修改后执行 `npm.cmd run build` 与 `npm.cmd run screenshots`，检查 desktop 和 mobile 全部页面。

### F2：影像叙事、轻交互、来源降噪与可访问性

- 将官方视频外链明确标注为“观看官方影像”，继续保持 link-only，不下载大型视频。
- 检查图片 `alt`、装饰图语义、键盘 focus、来源详情键盘展开和移动端横向导览。
- 为必要的展品增加轻量 hover、点击展开或锚点状态，不引入大规模粒子、旋转和新 WebGL 项目。
- 复核官方与开放许可媒体来源；许可不明确的内容保持外链，许可明确的本地素材保留署名与简写许可证。
- 再次执行构建、desktop/mobile 截图和视觉自检。

### F3：条件性终审

只有 F2 后仍存在明显遮挡、移动端溢出、英文可见标题、来源抢视觉或五厅布局过度相似时才执行；不为满足轮数强行创建。

## 交付与安全边界

- 最终截图归档到 `docs/screenshots/v5.0-f/`，移动端归档到 `docs/screenshots/v5.0-f/mobile/`。
- 更新中文 README、更新日志、AI 开发日志、F 迭代记录和本提示词档案。
- 不创建正式 `v5.0` 标签；F 完成后仅在全部自检通过时创建 `v5.0-f` annotated tag。
- 不执行强制推送、镜像推送、历史重写、旧标签删除、Git LFS 迁移和大型性能专项。
