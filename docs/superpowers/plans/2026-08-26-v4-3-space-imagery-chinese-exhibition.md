# V4.3 航天影像与全中文展陈优化计划

## 目标与范围

在不调整 React、Three.js、路由、采集或评分工具架构的前提下，校正五大展厅的图片展陈身份、补强东方红一号与神舟五号的历史事件叙事，并移除页面内的外文技术标注。

## 实施步骤

1. 审计 `src/assets/images/`、`src/data/assets.json` 与 `src/data/sources.json`，逐项给出展品类别；核对展厅中的主图、辅助图与技术图映射。
2. 从来源和授权明确的官方或 Wikimedia 历史资料中补充东方红一号与神舟五号真实任务影像；无法可靠取得的素材不纳入项目。
3. 以 SVG 重绘现有嫦娥一号与天问一号轨道资料中的外文技术标注；在来源记录中注明原始资料和“中文重绘，非官方原图”。
4. 为所有有本地图片的素材数据增加中文展品类别、面向参观者的简洁说明及来源名称；更新展厅主视觉，避免馆藏展品被表述为任务现场。
5. 调整图片组件与样式，使所有图片呈现“图片名称、展品类别、一句说明、来源”，不暴露 `main`、`secondary`、`technical`、`archive` 等内部字段。
6. 更新 V4.3 完整提示词、迭代记录、CHANGELOG、AI 开发日志和 README 版本号。
7. 运行数据完整性检查、生产构建和本地页面回归；生成五张 V4.3 页面截图。
8. 自查 diff 和 Git 状态；仅在验证通过且无无关文件时，使用中文提交、创建 `v4.3` 标签并推送 main 与标签。

## 验证

- `npm run build`
- JSON 解析与素材路径存在性检查
- 本地预览页面截图：首页、东方红一号、神舟五号、嫦娥系列、天问一号
- `git status --short` 与 `git diff --check`

## 风险与原则

- 不以技术图作为任务主视觉；不篡改历史照片。
- 仅对来源资料允许且技术名词已核对的示意图进行 SVG 中文重绘。
- 远程有新提交时停止推送，绝不 force push。
