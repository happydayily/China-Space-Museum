# V5.0：中国航天五大发展主线

## 目标

在不移除 V4.4.1 的 Three.js 场景、图片体系、任务过程、官方影像和 `MissionHall` 的前提下，将首页的五个任务入口升级为“序厅 + 五大主题展厅 + 具体展项”的信息架构。

## 实施步骤

1. 新建 `grandHalls.json` 与 `developmentLines.json`，集中定义五座大展厅、五条发展主线、关键节点、跨线技术关系与既有展项归属。
2. 扩展既有 `halls.json`，为五个保留任务页补齐 `grandHall`、关联主线和真正回答因果关系的 `whyItMatters`。
3. 新建大展厅与发展主线组件；大展厅展示核心问题、重要性、发展脉络、技术演进、关联关系、未来方向和可进入的既有详细任务页。火箭展厅嵌入原 `RocketGallery`。
4. 调整 `App.jsx` 的 hash 导航和首页，首页以五大发展主线作为一级入口，保留原有时间线、任务、火箭和技术树组件。
5. 调整 `MissionHall`，将“为什么重要”改为使用正式数据字段，保留其余 V4.4 功能。
6. 追加 V5 专属样式与响应式规则，保持暗色航天展陈风格。
7. 保存完整提示词、迭代记录并更新 README、CHANGELOG、AI 开发日志。
8. 校验 JSON 契约、执行 `npm run build`，在可用的本地浏览器能力下生成七张验收截图；再检查 Git 状态、提交、标签、推送和 Pages。

## 风险与边界

- 第一阶段只补齐结构和文本节点，不为次级节点批量下载未经核实的图片。
- 线上发布、推送、打标签均在本地构建通过后执行；不使用 force push。
- 截图依赖本机是否已有可用浏览器自动化工具；若不可用，需如实记录。
