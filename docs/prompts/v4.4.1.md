# V4.4.1 完整提示词：GitHub Pages 自动部署

当前项目：`I:\GitHub-practice\China-Space-Museum`

当前正式版本：V4.4

现在进行一个不修改网页内容的小版本：V4.4.1 —— GitHub Pages 自动部署。

## 目标

让中国航天数字博物馆通过公网网址直接访问，并在以后每次 `main` 分支更新后自动重新部署。

## 变更边界

不要修改 React 页面内容、Three.js 场景、航天数据、图片、展厅布局或 V4.4 任务过程，只处理部署。

## Vite 配置

检查 `vite.config.js`，保留现有配置并设置：

```js
base: '/China-Space-Museum/'
```

预期网址：<https://happydailyly.github.io/China-Space-Museum/>。

## GitHub Actions

创建 `.github/workflows/deploy-pages.yml`，触发条件为 push 到 `main` 和 `workflow_dispatch`，依次完成 checkout、Node LTS、`npm ci`、`npm run build`、上传 `dist` 与 GitHub Pages 部署。

## 验证与文档

本地执行 `npm ci` 和 `npm run build`。创建 `docs/prompts/v4.4.1.md`、`docs/iterations/v4.4.1.md`，更新 README、CHANGELOG 和 AI_DEVELOPMENT_LOG，记录公网部署原因、Pages 工作方式、网址和自动部署机制。

## Git 发布

构建成功后执行：

```text
git add .
git commit -m "V4.4.1：建立 GitHub Pages 自动部署"
git tag v4.4.1
git push origin main
git push origin v4.4.1
```

禁止 force push。若远程有新提交，停止并报告，不自动覆盖。

## 最终报告

报告 workflow 路径、Vite base、build 结果、commit hash、tag、push、Actions 启动状态、Pages 部署状态、最终公开网址和 git status。若 Pages 尚未开启，明确说明进入 `Settings → Pages`，在 `Build and deployment → Source` 选择 `GitHub Actions` 并保存。
