==================================================
一、本轮核心目标
==================================================

V4.3 暂时不要增加新的大型功能。

不要重构：

- React 架构
- Three.js 架构
- 路由体系
- 图片采集工具
- 图片评分工具

本轮只解决：

1. 航天图片与历史事件匹配度
2. 图片内部外文标注问题
3. 图片展陈身份不清晰的问题


==================================================
二、审计现有全部图片
==================================================

检查：

src/assets/images/
src/data/assets.json
src/data/sources.json


逐张判断现有图片属于：

A. 真实任务影像
B. 官方历史照片
C. 馆藏实物或复制品
D. 技术示意图
E. 任务成果图
F. 不适合继续展示


重点检查：

东方红一号
神舟五号
嫦娥系列
天问一号
中国空间站


禁止：

把馆藏模型描述成真实任务照片。

禁止：

把技术图作为任务主视觉。

禁止：

为了填满页面而使用关联性弱的图片。


==================================================
三、重点补强东方红一号
==================================================

当前东方红一号素材不足。

优先寻找：

1. 东方红一号相关历史影像
2. 长征一号发射或准备相关影像
3. 东方红一号馆藏实物
4. 东方红一号技术资料


优先来源：

- 中国国家航天局
- 新华社 / 新华网
- 中国科学院相关官方机构
- 中国科学技术馆
- Wikimedia Commons 中授权明确的历史资料


若找不到真正历史照片：

允许使用馆藏实物作为主展品，

但必须明确标注：

“馆藏实物 / 陈列展品”

不要让用户误认为是任务现场照片。


==================================================
四、重点补强神舟五号
==================================================

当前神舟五号主要是模型和复制品，
不够体现“首次载人航天”这一历史事件。

优先补充：

1. 神舟五号发射现场
2. 长征二号F发射影像
3. 航天员任务相关官方历史影像
4. 返回舱相关任务影像
5. 酒泉发射场任务资料


目标：

让用户第一眼理解：

“2003年，中国首次实现载人航天飞行。”

馆藏模型继续保留，
但不得作为唯一核心视觉。


==================================================
五、图片内部必须尽量中文化
==================================================

重点检查当前：

- 嫦娥一号结构示意图
- 天问一号轨道示意图
- 其他带英文、法文等外文标注的技术图片


原则：

优先顺序：

1. 寻找官方中文版技术图
2. 寻找可靠中文资料中的对应图
3. 如果授权允许且技术信息可以准确核对，
   则基于原始技术资料重新制作中文版示意图


禁止：

直接篡改真实历史照片内容。

禁止：

对不确定的技术名词进行猜测翻译。


如重新制作中文技术图：

优先使用：

SVG / HTML / Canvas

而不是低清位图。

要求：

所有技术标注使用中文。

同时在 sources.json 中记录：

- 原始资料来源
- 中文重绘说明
- 是否属于重新绘制，而不是官方原图


==================================================
六、建立更清晰的图片展陈身份
==================================================

网页中所有图片增加明确类别标识。

只使用中文：

真实任务影像
历史档案
馆藏展品
技术图解
任务成果


例如：

东方红一号模型：

馆藏展品

真实任务影像


天问一号地火轨迹图：

不得在页面显示：

main
secondary
technical
archive

这些内部程序字段。


==================================================
七、图片说明优化
==================================================

每张展品图片至少包含：

图片名称
展品类别
一句中文说明
来源


例如：

嫦娥六号着陆器和上升器月面合影

【真实任务影像】

嫦娥六号在月球背面完成采样任务期间获取的任务影像。

来源：中国国家航天局


图片说明要求：

简洁
准确
面向普通参观者

不要像数据库字段。

十三、验证
==================================================

执行：

npm run build


检查：

1. 构建成功
2. 页面无 JavaScript 报错
3. 图片路径不存在的数量
4. 是否仍存在英文 UI
5. 是否仍有明显外文技术图
6. 是否有馆藏模型被误标为任务照片
7. git status


如果验证失败：

不要提交和 push。

先修复。


==================================================
十四、Git 提交与上传
==================================================

只有全部验证通过后才执行。


首先检查：

git status
git diff


确认没有：

node_modules
dist
images.zip
缓存
浏览器 Profile
隐私信息
无关文件


然后：

git add .


创建中文提交：

git commit -m "V4.3：优化航天影像与全中文展陈"


创建标签：

v4.3


上传主分支：

git push origin main


上传标签：

git push origin v4.3


如果远程分支比本地更新：

禁止 force push。

先停止并报告，
不要自动覆盖远程提交。
