# V5.0-RC2-PC 中文开发记录

本轮目标为“中国航天数字博物馆：产品化、启动体验与最终 PC 展陈完善”。

- 只维护 PC，验收视口固定为 `1600×900`、Microsoft Edge。
- 保留首页、五大发展主线、五个主题展厅、任务展项和五个独立 Story。
- 移动端、平板端、390px、768px、响应式全面重构和移动端截图冻结。
- 新增纯 CMD `中国航天博物馆启动器.cmd`，双击后检查本地环境、调用 `npm.cmd run dev`、等待本地服务并自动打开 Edge。
- 增加克制的“在线展馆”入口，在线版与本地版共用同一套页面内容。
- 不新增无必要图片或视频；官方视频保持 link-only；截图只覆盖 `docs/screenshots/review/latest/` 六张 PC 图。
- 完成 build、截图、真实浏览器路由/资源/交互验收后，提交 `V5.0-RC2-PC：产品化与桌面端终审`，创建并推送 `v5.0-rc2-pc`，不创建正式 `v5.0` Tag，不开始 RC3。
