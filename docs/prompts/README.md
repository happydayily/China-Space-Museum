# Codex/AI 提示词档案

本目录专门保存每次提交给 Codex 或其他 AI 工具的主要开发提示词。提示词档案用于还原人工需求、约束条件、验收重点和迭代背景。

## 记录规则

- 所有提示词使用中文保存。
- 尽量保存真正交给 Codex/AI 的完整提示词，不只保存简略摘要。
- 每轮迭代使用版本号命名，例如 `v4.3.md`。
- 每份提示词至少包含：本轮目标、完整提示词、为什么提出这些要求、人工验收重点。
- 提示词中如果包含英文代码、命令、路径或 API 名称，应原样保留，便于复现。
