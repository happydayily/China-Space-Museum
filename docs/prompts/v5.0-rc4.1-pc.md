# V5.0-RC4.1-PC 中文开发提示词

继续维护中国航天发展史数字博物馆。基线为已推送的 `v5.0-rc3-pc`，只维护 `1600×900` PC 桌面端。

本轮目标是“最后的策展去模板化”：

1. 为进入太空、天基中国、人在太空、奔向月球、走向行星的 Deep Dive 使用明确不同的叙事标题和说明，不再显示统一的“重点展项 · 深入了解”。
2. 媒体卡默认只显示来源机构、年份和“来源详情 ↗”；作者、许可、原始标题、URL、授权状态等完整登记必须保留在可展开详情中。
3. 首页“关键时刻”改成历史展墙，不做 Dashboard 式等权卡片；保持 Hero、五条主线、入馆导言、关键时刻和技术底座五段结构不变。
4. 天基中国保持三个问题，但把问题接到卫星真正产生的结果和既有风云、北斗、高分证据；不为填充页面重复素材。
5. 载人航天不增加人物；杨利伟、翟志刚、景海鹏必须回到首次载人、首次出舱和空间站能力节点。
6. 奔向月球保持“绕 → 落 → 回”主路线，把月背做成“通信 → 软着陆 → 采样返回”的简单工程支路，并保留嫦娥六号、2024、1935.3 克和官方来源。
7. 走向行星保持距离、发射窗口、转移轨道、通信时延、自主运行和“绕/落/巡”，降低解释卡片噪声，真实天问和祝融影像优先。

约束：不改移动端、平板端、启动器和 Three.js 架构；不新增大型区块，不新增无明确许可的媒体，不创建正式 `v5.0` Tag。每轮只生成 `docs/screenshots/review/latest/` 下六张 PC fullPage PNG。先 build、截图并读取六张图，再只处理最多两项最终问题。
