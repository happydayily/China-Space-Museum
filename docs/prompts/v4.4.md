# V4.4 完整中文开发提示词

当前项目：

I:\GitHub-practice\China-Space-Museum

当前正式版本：

V4.3

现在进入：

V4.4 —— 重构任务过程与官方影像

本轮核心问题：

当前所有展厅共用的“任务轨迹”展示过于模板化。

现有形式大多只是：

地球 → 发射 → 中间轨道 → 返回

不同任务看起来几乎相同，不能体现神舟、探月、火星探测和空间站建造各自真正的任务特点。

因此本轮不要简单美化现有轨迹。

需要重新判断：

哪些任务适合轨迹动画，哪些任务适合阶段流程，哪些任务适合建造过程。

==================================================
一、总体原则
==================================================

将页面中的统一标题：

“任务轨迹”

改为：

“任务过程”

或者根据具体任务使用：

“飞行过程”
“探月过程”
“火星探测过程”
“空间站建造过程”

禁止所有任务继续共用同一条弧线模板。

如果某个可视化不能帮助用户理解任务，宁可删除，也不要为了有动画而保留。

==================================================
二、东方红一号
==================================================

东方红一号不需要复杂 Three.js 轨迹。

改为简洁的历史任务流程：

01 长征一号发射
02 卫星进入预定轨道
03 东方红一号开始在轨运行
04 《东方红》乐曲信号播发

重点体现：

“中国第一次把自己的卫星送入太空”。

可采用：

横向阶段时间线
+
历史档案图片

不需要无意义的飞行小球动画。

==================================================
三、神舟五号
==================================================

神舟五号可以保留轨道动画，但必须体现真实任务特征。

阶段至少包括：

01 酒泉发射
02 船箭分离并进入近地轨道
03 杨利伟在轨飞行
04 绕地飞行14圈
05 制动离轨
06 返回舱再入大气层
07 内蒙古主着陆场返回

在页面中突出：

飞行时间：21小时23分

绕地：14圈

不要只显示：

地球 → 发射 → 轨道 → 返回。

如果继续使用动画：

轨道必须明确表现近地绕飞，并配合阶段文字逐步点亮。

==================================================
四、嫦娥系列
==================================================

嫦娥系列不能再使用单一任务模板。

增加任务选择：

嫦娥一号
嫦娥三号
嫦娥五号
嫦娥六号

分别展示不同任务特点。

其中嫦娥六号重点做完整流程：

01 发射入轨
02 地月转移
03 近月制动
04 环月飞行
05 着陆下降
06 月背着陆
07 月背采样
08 月面起飞
09 月轨交会对接与样品转移
10 月地转移
11 再入返回地球

建议采用：

地球 / 月球双天体示意
+
阶段线路
+
阶段逐步点亮

不要使用普通抛物线。

==================================================
五、天问一号
==================================================

天问一号必须体现火星任务特点：

01 文昌发射
02 地火转移
03 火星捕获
04 火星停泊轨道
05 着陆巡视器分离
06 进入火星大气
07 减速、悬停避障和软着陆
08 祝融号驶离着陆平台
09 火星表面巡视
10 环绕器进行中继与科学探测

建议：

太阳—地球—火星简化关系图
+
火星局部着陆阶段
+
祝融号巡视阶段

可以分成：

“奔火”
“落火”
“巡火”

三个视觉章节。

==================================================
六、中国空间站
==================================================

中国空间站不要再显示“任务轨迹”。

彻底改为：

“空间站建造过程”

展示：

01 天和核心舱发射
02 问天实验舱发射并对接
03 问天转位
04 两舱形成L字构型
05 梦天实验舱发射并对接
06 梦天转位
07 三舱形成T字基本构型
08 进入长期在轨运营

尽可能用简化舱段图形动画：

天和
+
问天
+
梦天

逐步组合。

这部分应该成为空间站展厅的特色展示，而不是轨迹图。

==================================================
七、增加“官方影像”模块
==================================================

在每个任务过程模块之后增加：

“官方影像”

不要下载大型视频文件进入项目。

建立：

src/data/mediaLinks.json

字段：

id
mission
title
type
source
url
description

type 可使用：

官方视频
官方图集
官方回顾

优先来源：

- 中国国家航天局
- 中国载人航天工程官网
- 新华社/新华网
- 央视官方平台

禁止：

- 不明搬运视频
- 无来源短视频
- 个人剪辑
- AI生成视频

页面采用：

封面卡片
+
标题
+
来源
+
“查看官方影像”

点击后打开官方页面。

如果官方页面本身支持稳定的视频嵌入，可以评估嵌入。

否则默认外链打开。

重点寻找：

神舟五号官方任务回顾

嫦娥五号/嫦娥六号任务过程视频

天问一号着陆与祝融号巡视实拍视频

中国空间站建造和转位过程视频

==================================================
八、页面设计
==================================================

任务过程模块不能占据巨大空白区域。

要求：

- 信息密度适中
- 阶段名称字体清晰
- 中文为主
- 不出现英文步骤
- 每个节点有真实含义
- 支持逐阶段高亮

桌面端应尽量一屏或一屏半看清主要过程。

==================================================
九、技术实现
==================================================

不要为了复用而强迫所有任务使用同一个组件表现形式。

允许：

MissionProcess/
├─ CrewedOrbitProcess
├─ LunarProcess
├─ MarsProcess
├─ StationAssemblyProcess
└─ HistoricalProcess

也可以采用一个数据驱动组件，但必须支持不同布局类型。

新增：

src/data/missionProcesses.json

每个任务明确记录自己的阶段。

不要将大量阶段文字硬编码在 JSX 中。
