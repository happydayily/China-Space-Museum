# V5.0-E3 中文开发提示词

继续开发 `I:\GitHub-practice\China-Space-Museum-clean` 的 V5.0-E3。

## 本轮目标

在 V5.0-E2 已完成媒体融合和人工截图验收的基础上，完成数字博物馆展陈视觉基线。保持五大发展主线、五大主题展厅、GrandHall 路由、五个独立 Story、现有任务详情和媒体来源体系，不进入 V5.0-F。

## 视觉要求

- 统一深海军蓝、纸张白、冷灰白、灰紫白、沙灰、墨色、细分隔线和铜金色彩 token。
- 首页首屏保持深色，主线地图和关键时刻使用浅色，共同技术底座保留深色。
- 五个展厅 Hero 保持深色，但正文、为什么重要、主要 Story 和尾部使用轻量纸张背景。
- 五厅使用低饱和且可区分的强调色：铜橙、蓝青、灰绿、灰紫、沙红。
- 减少大面积渐变、发光、模糊、厚阴影和密集边框，保留必要暗场、轨迹、火箭、卫星与深空关系。
- 统一中文系统字体栈，控制 Hero、Story、正文、说明和来源字号，保证普通正文不被过度放大。
- 来源、作者、文件名、许可证链接和完整署名默认收进“来源详情”；普通页面显示中文标题、年份、来源机构和许可证简写。
- 已完成、进行中、规划中使用统一状态表达，不能只依赖展厅颜色。

## 内容与边界

- 不新增未经核实的媒体，不修改历史事实和任务数据含义。
- 不新建几十个页面，不重构 Three.js，不进行性能拆分，不进入 GitHub Pages 专项。
- 进入太空、天基中国、人在太空、奔向月球、走向行星必须保持独立叙事，不使用同一套模板替代不同任务逻辑。
- 任务级 `whyItMatters` 与展厅级 `hallWhyItMatters` 必须分层。
- 媒体作为对应叙事节点出现，不恢复统一媒体墙。

## 验证要求

- 执行 `npm.cmd run build`。
- 执行 `npm.cmd run screenshots`。
- 自动生成首页及五个真实展厅的六张 1600×900、fullPage、PNG 截图。
- 检查六个文件存在、非空、无明显错误页、无 Vite 错误覆盖层、无明显 404 或图片加载失败。
- 普通开发截图只覆盖 `docs/screenshots/review/latest/`；明确版本才复制到版本归档目录。
- 完成后报告修改摘要、构建结果、截图路径和遗留问题，等待视觉验收。
