# V5.0-RC3.1-PC 中文开发记录

本轮目标：在 `v5.0-rc2-pc` 基础上完成“中国航天发展史数字博物馆”RC3.1 策展与内容深化，只维护 `1600×900` PC 桌面端。

执行边界：不修改移动端、平板端或响应式结构；不修改纯 CMD 启动器；不新增授权不明的本地图片、视频、程序或依赖；不创建正式 `v5.0` Tag。

重点要求：

- 首页增加克制的入馆导言，让 Hero、五条主线、关键时刻和技术底座形成序厅阅读顺序。
- 修正主线年份轴，确保 1988、2013、2016、2021 等已使用节点落在正确位置。
- 时间线和技术底座表达主次与支撑关系，减少普通 Dashboard 的等权卡片感。
- 进入太空表达高度、运力、轨道和任务边界；天基中国围绕北斗、风云、高分的三个生活问题组织内容；人在太空只加入少量与能力节点相关的人物；奔向月球补充嫦娥六号月背 1935.3 克采样返回事实；走向行星表达发射窗口、通信时延和自主运行的工程影响。
- 保持五个独立 Story、官方媒体 link-only、开放许可本地素材、外链 `target="_blank" rel="noreferrer"` 和既有旧任务路由。
- 完成构建、六张 PC fullPage 截图、Edge 路由/资源/交互/console/404/overflow QA，再进入下一轮视觉终审。
