# V4.2 Codex 开发提示词

## 本轮目标

从 V4.2 开始正式使用 Git/GitHub 管理“中国航天发展史数字博物馆”项目，并完整记录人工需求、AI/Codex 修改、人工验收和后续迭代过程。本轮只建立中文记录体系和干净 Git 基线，不 push GitHub。

## 完整提示词

当前项目是一个使用 React + Vite + Three.js 开发的“中国航天发展史数字博物馆”。项目负责人已经确认 `src/assets/images.zip` 是以前传输图片素材使用的压缩归档，目前不再需要。不要再次检查、解压、比较或删除它；将它加入 `.gitignore`，但保留本地文件。

请在项目根目录创建 `.gitignore`，至少排除 `node_modules/`、`dist/`、`.vite/`、`*.log`、`src/assets/images.zip`、`tmp/`、`temp/`、`cache/`、`coverage/`、`docs/chrome-*/`、`docs/edge-*/`，以及浏览器 Profile、Cookies、Cache、History 等临时数据。同时确保 `src/`、`src/assets/images/`、`src/data/`、`tools/`、`docs/screenshots/`、`docs/iterations/`、`docs/prompts/`、`package.json`、`package-lock.json`、`vite.config.js`、`README.md`、`CHANGELOG.md` 和 `AI_DEVELOPMENT_LOG.md` 可以被 Git 跟踪。

创建 `docs/iterations/` 和 `docs/prompts/`，所有 Markdown 文档使用 UTF-8 编码。创建 `docs/iterations/000-pre-git-history.md`，用中文回顾 V1 基础时间轴网页原型、V2 星空与航天视觉和初步交互、V3.1 航天数据层、V3.2 数字资产管理系统、V3.3 图片自动采集和质量评分、V3.4 重点航天素材、V4 五大主题展厅、V4.1 中文化/字体/图片角色调整、V4.2 展陈布局/时间线/火箭谱系精修。必须明确这些阶段发生在 Git 正式版本管理以前，回顾根据现有资料整理，不伪造过去不存在的 Git 提交。

创建 `docs/prompts/README.md`，说明该目录保存每次提交给 Codex/AI 的完整中文提示词，并说明以后每次版本迭代使用类似 `v4.3.md` 的文件，至少包括“本轮目标”“完整提示词”“为什么提出这些要求”“人工验收重点”。为本轮创建 `docs/prompts/v4.2.md`，保存本提示词的完整中文内容。

检查并完善全中文为主的根目录 `README.md`，至少包含项目名称、项目简介、当前版本 V4.2、当前能力、技术栈、本地运行方法、项目结构、图片和资料来源说明、AI 辅助开发说明、迭代记录入口、Codex 提示词档案入口和后续计划。创建中文 `CHANGELOG.md`，说明 V4.2 是第一次进入正式 Git 版本管理的基线版本。创建中文 `AI_DEVELOPMENT_LOG.md`，包含 V4.2 的人工目标、给 Codex 的主要要求、Codex 完成内容、人工验收结果、存在问题和下一版本计划。

如果尚未初始化 Git，执行 `git init`，然后执行 `git status`，确认 `node_modules/`、`dist/`、`src/assets/images.zip`、`.vite/`、缓存和临时目录没有进入待跟踪文件，同时确认 `src/assets/images/` 中真实网页图片仍然会被跟踪。输出 Git 准备跟踪的文件数、被忽略的主要文件、预计首次提交大小和异常文件检查结果。

确认没有异常后执行 `git add .`，使用中文提交说明 `V4.2：建立中国航天数字博物馆版本管理基线` 创建第一次正式提交，并创建本地标签 `v4.2`。不要 push GitHub，不要删除 `images.zip`，不要删除 `node_modules`，不要修改网页业务代码、React、Three.js 或航天数据。

## 为什么提出这些要求

项目需要从旧开发目录复制状态转入可复现、可追踪的 Git 工作流。依赖目录、构建产物、缓存和本地浏览器数据不属于源代码，加入 Git 会造成仓库膨胀、隐私泄露和后续协作困难。中文文档和完整提示词档案用于保留人工决策与 AI 辅助开发过程，便于后续版本验收和复盘。

## 人工验收重点

- `.gitignore` 已创建，且 `src/assets/images.zip` 仅被忽略、没有被删除。
- `node_modules/`、`dist/`、`.vite/`、缓存、临时目录和浏览器 Profile 未进入 Git。
- `src/assets/images/`、`src/data/`、`tools/` 和必要文档进入 Git。
- 根目录 README、CHANGELOG、AI 日志及新增档案为中文。
- 首次提交说明为中文，提交成功并创建 `v4.2` 标签。
- `git status` 最终干净，且没有 push 到远程仓库。
